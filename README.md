# Radial-Convergences_Anwendungsentwicklung_Projekt_SoSe26_
Interaktive Visualisierung der Handelsbeziehungen zwischen europäischen Ländern mithilfe von HTML, CSS und JavaScript.

## Funktionen

- Interaktive Visualisierung als radiales Netzwerk
- CSV-Datenimport
- Dynamische Hervorhebung von Knoten
- Filterung von Kanten
- Tooltips zur Anzeige des Handelsvolumens
- SVG-Rendering

## Technologien

- HTML5
- CSS3
- JavaScript (ES6)
- SVG
